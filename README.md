# Curso Completo de Angular  

¡Bienvenido! Este curso me ha proporcionado las herramientas necesarias para dominar Angular (la última versión) desde cero hasta construir aplicaciones robustas y escalables. A través de ejercicios prácticos y tareas, aprendí a manejar TypeScript y todas las características fundamentales de Angular.  

## Lo que aprendí:  

- **Fundamentos de TypeScript y ECMAScript**  
- **Creación de mi primer "Hola Mundo" en Angular**  
- **Componentes, Directivas y Servicios**  
- **Gestión de Módulos y Pipes**  
- **Rutas y Rutas Hijas**  
- **Carga Perezosa (Lazy Loading)**  
- **Guards y Protección de Rutas**  
- **Autenticación con JsonWebTokens**  
- **Integración de Mapas y APIs**  
- **CRUD y SPA**  
- **Utilización de Git y GitHub**  
- **Despliegues a producción**  
- **Conexión con MongoDB y Node.js**  
- **Reutilización de Componentes**  
- **Uso de Extensiones Reactivas y Librerías de terceros**  
- **Diseños con PrimeNG, Material Design, Bootstrap y Tailwind**  
- **Señales, Efectos y Componentes Standalone**  

Este curso fue integral y está diseñado para que me desarrolle con confianza en el ecosistema de Angular, abordando no solo la creación de aplicaciones, sino también la lectura de documentación, la solución de errores y la optimización de código. ¡Estoy emocionado de aplicar todo lo aprendido en el mundo de Angular!
